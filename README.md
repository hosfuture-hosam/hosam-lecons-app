# بناء تطبيق أندرويد (APK) عن طريق GitHub Actions

هذا المجلد جاهز لرفعه على GitHub عشان يبني ملف APK تلقائيًا في السحابة، من غير ما تحتاج جهاز فيه إنترنت قوي أو مساحة كبيرة.

## محتويات المجلد

```
main.py                          # كود التطبيق (لازم يفضل اسمه main.py)
pyproject.toml                   # إعدادات التطبيق (الاسم، معرف الحزمة)
requirements.txt                 # المكتبات المطلوبة (flet)
.github/workflows/build-apk.yml  # سكريبت البناء التلقائي
```

## الخطوات

### 1. عمل حساب ومستودع (Repository) على GitHub
- روح على https://github.com واعمل حساب لو معندكش.
- اضغط "New repository"، اديله اسم (مثلاً `hosam-lecons-app`)، واختار **Public** (مجاني بدون حدود دقائق تشغيل) أو Private.

### 2. رفع الملفات
من جهازك، افتح Terminal / CMD جوه المجلد ده ونفّذ:

```bash
git init
git add .
git commit -m "أول نسخة من التطبيق"
git branch -M main
git remote add origin https://github.com/USERNAME/hosam-lecons-app.git
git push -u origin main
```
(غيّر `USERNAME` و `hosam-lecons-app` باسمك واسم المستودع الحقيقي)

> ملحوظة: لو مش مرتاح للأوامر دي، تقدر برضو ترفع الملفات مباشرة من واجهة GitHub بالسحب والإفلات (drag & drop) — بس لازم تحافظ على مسار الملف `.github/workflows/build-apk.yml` بالظبط زي ما هو.

### 3. تشغيل عملية البناء
- روح لصفحة المستودع على GitHub، ادخل تبويب **Actions**.
- هتلاقي عملية "Build Android APK" شغالة تلقائيًا (لو عملت push)، أو اضغط عليها واختار **Run workflow** لتشغيلها يدويًا.
- انتظر — أول مرة ممكن تاخد من 15 لـ 40 دقيقة (لأنها بتحمّل Flutter وAndroid SDK كاملين).

### 4. تحميل ملف الـ APK
- بعد ما تخلص العملية بنجاح (علامة ✔️ خضرا)، افتح صفحة العملية.
- تحت هتلاقي قسم **Artifacts** فيه ملف اسمه `hosam-lecons-apk` — حمّله (هيكون ملف zip فيه الـ APK جواه).

### 5. تثبيت التطبيق على الموبايل
- انقل ملف الـ APK للموبايل (واتساب لنفسك، Google Drive، كابل USB... أي طريقة).
- من إعدادات الأندرويد، فعّل "**تثبيت من مصادر غير معروفة**" لمرة واحدة.
- افتح الملف وثبّته زي أي تطبيق عادي.

## لو حصل خطأ في البناء
- افتح صفحة العملية الفاشلة في تبويب Actions وشوف تفاصيل الخطأ في خطوة "Build Android APK".
- الأخطاء الشائعة غالبًا بتكون بسبب مساحة تخزين قليلة (نادر مع GitHub) أو مشكلة في اسم الحزمة (`org` في `pyproject.toml`) — تأكد إنه إنجليزي بدون مسافات أو رموز.
